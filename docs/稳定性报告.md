## 翻转题

无。

因此本轮没有“具体问题和根因”可列。这里的“无翻转”不是用总分掩盖：逐题表里 30 题全部 3/3，2/3、1/3、0/3 都是 0。若下一轮出现翻转，应保留每次运行的 `status`、`error_code` 和 `rows_sample`，按题定位，而不是只看总分。

## 为什么本轮稳定

- LLM 调用使用 `temperature=0`，同一提示和同一模型下输出更稳定。
- 时间锚点使用数据截止日，不随运行当天变化。
- 评测比较的是执行结果等价，不是 SQL 字符串，写法差异不会误判。
- clarify / unsupported 题是显式期望，当前题集没有出现“同一题有时澄清、有时执行”的翻转。

这些条件只能解释本轮为什么没有翻转，不能证明模型在所有问题上都稳定。
